# Chimera

Grow a creature from your own genome, swallow smaller ones, and share a body with one other head.

Играть: https://pnthv.itch.io/chimera-world

Вся игра — один файл `index.html`, сборка не нужна. Локально достаточно открыть его в браузере.

При каждом push в `main` GitHub Actions заливает игру на itch.io ([.github/workflows/itch.yml](.github/workflows/itch.yml)).
